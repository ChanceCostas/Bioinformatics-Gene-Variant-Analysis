# Bioinformatics: Gene Variant Analysis

Analyzing where harmful, harmless, and uncertain gene variants fall along a protein, using public databases and Python.

**Question:** Where do variants labeled harmful fall along a protein compared with variants labeled harmless or uncertain, and do the harmful ones cluster in particular protein regions?

**Why It Matters:** A lot of gene variants are labeled as uncertain, which means researchers don’t know if they cause disease. This project looks at where uncertain variants fall compared with known harmful ones to find any patterns. It is a student review of public data, not a clinical tool.

**Gene:** One gene, RYR-1

**Data:** ClinVar, UniProt, and gnomAD (public data only). Download dates: Nov. 2026

**Tools:** Python, pandas, Biopython, matplotlib

**Note:** This project describes patterns in public data. It does not give medical advice.
